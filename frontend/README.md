# Page Pulse Frontend

A modern React + Vite frontend for the Page Pulse website auditing tool.

## Features

- ⚡ Fast with Vite and React
- 🎨 Modern UI with Tailwind CSS
- 🌙 Dark mode support
- 📱 Fully responsive
- ♿ Accessible
- 🎯 Form validation
- 💾 localStorage integration
- 🔄 Real-time error handling

## Getting Started

### Installation

```bash
cd frontend
npm install
```

### Development

```bash
npm run dev
```

The app will open at `http://localhost:3000`

### Build

```bash
npm run build
```

## Tech Stack

- **React 18** - UI library
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Axios** - HTTP client
- **Lucide React** - Icons
